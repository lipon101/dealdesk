    How to change the admin passphrase
    
    
      
  1. Open the admin panel, log out, then open this page in a new tab.
    2. 
      
  2. Type (or generate) a strong passphrase — 16+ chars, mixed case, digits and symbols.
    3. 
      
  3. Click Generate hash and copy the JSON block.
    4. 
      
  4. Open admin-config.js next to the admin page and replace the three values (salt, iterations, hash).
    5. 
      
  5. Save, upload to your host, and log in with the new passphrase. Never store the plaintext passphrase in the file.
    6. 
    

    
The same values are used for the Cloudflare Worker secrets (ADMIN_SALT, ADMIN_HASH, ADMIN_ITER) if you deploy the backend — see the README §6.
