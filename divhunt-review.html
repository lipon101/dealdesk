What Divhunt actually does

Divhunt is a visual website builder designed for both coders and non-coders. Rather than rows-and-columns templates, it gives you a free-form canvas: you place components anywhere, switch views to suit your process, and every page loads as part of a single-page application — no full reloads between pages, no slow round-trips on content changes.

The platform splits into six areas:

  • Visual builder — a code-free canvas with optional CSS access for fine control, unlimited pages, live preview and live collaboration
  • CMS — collections with unlimited fields, plus custom files, so content-driven sites scale beyond page-by-page editing
  • REST API integration — connect and consume any REST API visually, defining endpoints, headers, body, authentication and query parameters without code, with operations running securely on the backend
  • Plugins — all current and future plugins, plus a marketplace to build and sell your own custom plugins or templates
  • Localization — up to 15 languages per site, plus all future languages
  • Workflows & code export — automate processes and export the code when you need to take it elsewhere

There is also built-in SEO, form building with email or integration delivery, connect-domain support, and the ability to remove Divhunt branding. For teams, unlimited collaborators and live preview across tabs round out the pitch.

How we tested the platform

Website builders are judged by the sites they ship, so we ran a controlled protocol:

Build: create a multi-page marketing site from a blank canvas, adding CMS collections and a contact form

Connect: consume a public REST API visually and render its data through the CMS

Publish: preview live in another tab, then check the export and localization options

The results: the canvas feels genuinely free-form after a short orientation, page switches are instant (the SPA architecture is real), and connecting a REST API visually worked without writing a line of code. The trade-offs are a steeper learning curve than template builders and per-site license math that changes how agencies should tier.

Feature deep dive

The free-form canvas

Most “website builders” are glorified template editors. Divhunt is a free-form canvas where you build in whatever view suits your process — and because it is a single-page application, pages load instantly as you switch and visitors get zero refresh time between pages. Optional CSS access gives developers the escape hatch template tools usually block.

CMS without the WordPress tax

CMS collections with unlimited fields let content teams update sites without touching design. Add custom files, connect domains, and you have the content-modeling core of Webflow at a fraction of the subscription cost — with unlimited pages included on every tier.

Visual REST API connections

Divhunt lets users define endpoints, headers, body, authentication and query parameters inside the visual interface, with all operations running securely on the backend. For non-coders, this opens data-driven sites that would otherwise require a developer; for developers, it speeds up the boring integration work.

Plugins and marketplace

The deal includes all current plugins plus all future plugins, and the Divhunt marketplace lets you build and sell custom plugins or templates — an income stream for freelancers who standardize their own components.
